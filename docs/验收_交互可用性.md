## 三、无用 / 死交互清单

### P0（页面崩溃，阻断整页功能）
1. **证据包 /evidence 整页白屏**
   - 现象：路由可进、顶栏/侧栏正常，但 main 区为空（`main.children===0`，无 `.af-page`），页面 11 个交互（构建/详情/冻结/导出×2/模板×3/查询）全部不可达。
   - 根因（源码核对）：`webui/src/views/EvidenceView.vue` 第 93 行使用 `computed(...)`，但第 3 行只 `import { reactive, ref, onMounted } from 'vue'`，**漏导入 computed** → 组件 setup 运行期 ReferenceError → Vue 渲染失败白屏。
   - 证据：编译产物 EvidenceView-*.js 中 `T=computed(...)` 而 import 清单无 computed；页面 console 无自定义错误（Vue 吞掉），但 main 区 0 子节点。
   - 建议：第 3 行补 `computed`（一行修复）；并在验收中补 EvidenceView 回归（构建/冻结/导出/模板）。

### P1（误导性交互反馈）
2. **看板「应对骗子」在 LLM 未配置时 toast 谎报成功**
   - 现象：提交骗子私信 → toast"应对回复已生成"，但结果区 reply="—"、reasoning="未命中应对规则"、IOC 全空。
   - 定位：`BoardView.vue` respond 流程对后端空结果仍 ElMessage.success。
   - 建议：当 reply 为空时改提示"LLM 未配置或未命中套路，未生成可用回复"，避免操作员误以为已回复骗子。

### P2（展示/文案/体验缺陷）
3. **知识库「蒸馏成语条」分词质量差**：实测内容含"冒充银行客服"，蒸馏出的 pattern="充银"（`_extract_keywords` 2-4 字高频片段抽取的断词残片），会污染话术库命中。建议对 pattern 增加最小语义校验或改用更有意义的 subject。
4. **CoverView 嵌套图谱不显示假联系信息**：`/cover/map` 返回的 tree 节点不含 fake_phone/fake_wechat/fake_qq 字段（仅 identities 数组含），前端图谱行 `safeMask(n.fake_phone)` 恒为"—"——即使身份已配置假手机号，图谱也看不到。建议后端 tree 节点带上 fake_* 字段或前端从 identities 映射。
5. **删除伪装不级联接触记录**：删除身份 B 后其接触记录仍保留（contact #21 引用已删 identity_id=25），UI 删除弹窗文案"其下所有接触记录将由后端级联处理"与实际行为（`cover.py delete` 注释明确"接触事件保留（审计）"）不符。属设计（审计留痕）但文案误导。建议改文案为"接触记录保留用于审计，将显示为「伪装 #已删除」"；且**无接触记录删除接口**，误登记无法清理。
6. **非本机访问复制类按钮全部失败**（CoverView 复制原文、顶栏复制 key）：navigator.clipboard 需安全上下文；已有优雅降级 toast，但远程访问场景该按钮不可用。建议提示信息包含"本机浏览器或 HTTPS 下可用"。
7. **覆盖提示信息中的少量误导**：dashboard 顶部"一键登录（本机）"按钮在远程访问时点击无响应（应提示 403 loopback_only 原因，实际无任何反馈——见 §四-4 实测）。

### 非缺陷说明（避免误报）
- 聊天导入/控制台/知乎 cookie 等依赖本机环境的功能，环境未就绪时均有明确提示与重试路径，**不是死按钮**。
- 设置页 key 查看/重置远程 403 是安全设计（loopback_only），页面有明确告警文案。

## 五、总评

- 全站 24 个路由页面，23 个页面交互**真实可用且有意义**：每个按钮点击都有对应后端效果与前端反馈（toast/列表刷新/抽屉），表单校验与后端 422/403 语义对齐（前端统一转可读提示），敏感操作（退役/删除/冻结/启停/发布案例/蒸馏）全部强制 confirm+reason≥20 审计。
- CoverView（反钓鱼伪装）是本轮重点：档案树/创建 layer+1/启停/主动暴露/登记接触/接触筛选/嵌套图谱 **7 条交互链路全部实测通过**，HITL 合规、脱敏、审计都到位。
- **唯一阻断性缺陷：/evidence 证据包页 P0 白屏（computed 漏导入）**，证据相关操作目前只能走 API。
- 次要改进：应对骗子虚假成功提示（P1）、蒸馏分词质量（P2）、图谱假信息不显示（P2）、删除文案误导（P2）、复制按钮远程不可用提示（P2）。
