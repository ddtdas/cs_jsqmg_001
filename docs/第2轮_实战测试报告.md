## 3. 问题清单（分级）

### P0（阻断级）

**P0-1｜[E3] 422 错误回显含 admin key（验证回显泄露）**
- 位置：app/utils.py validation handler
- 根因初判：input 字段回显
- 建议修复：错误消息不包含请求体敏感字段

### P1（严重）

**P1-1｜[A2] 并发 reset 后 api_keys 表 enabled=1 行数=12（≠1）**
- 位置：app/api/auth.py reset_key
- 根因初判：并发下旧哈希 disable 与新哈希 enable 无事务互斥，表状态与文件不一致
- 建议修复：reset-key 串行化（进程内锁 + 文件锁）
**P1-2｜[A4] local-login 无 Origin/Sec-Fetch-Site 校验 + 无 CORS 限制（DNS-rebinding 攻击链：攻击者域名解析到 127.0.0.1，恶意页面可同源读取 local-login 响应窃取 admin key）**
- 位置：app/api/auth.py _require_loopback / local_login
- 根因初判：仅校验 TCP 对端回环，不校验 Origin/Host/Sec-Fetch-Site；响应无 ACAO 限制（CSP connect-src 'self' 只保护本地页面，rebinding 场景可绕过）
- 建议修复：local-login/current-key 校验 Origin 与 Sec-Fetch-Site 须为本机 http://127.0.0.1:9200 或缺失；Host 头白名单 127.0.0.1/localhost；响应头加 'Access-Control-Allow-Origin' 限制；或加 X-Requested-With/同源校验
**P1-3｜[A5] admin key 熵仅 32 bit（2^32 可离线爆破）**
- 位置：app/deps.py:46 load_or_create_bootstrap_key + app/api/auth.py:138 reset_key
- 根因初判：secrets.token_hex(4) = 8 hex = 32 bit
- 建议修复：改为 token_hex(16) 或 32（≥128 bit），旧 key 兼容迁移
**P1-4｜[B7] 超 int64 路径参数触发 500 并泄露异常类名（OverflowError）——可被任意请求触发，属拒绝服务/健壮性缺陷**
- 位置：app/api/traps.py 等路径参数 int + sqlite3 绑定 2^63 溢出
- 根因初判：路径参数未做 int64 范围校验，sqlite3 绑定 20 位整数抛 OverflowError → 未捕获 500（utils.py 回显类名）
- 建议修复：路径/body 整数参数加范围校验（如 1≤id≤2^63-1 → 422）；utils.py 去掉异常类名回显（联动 E3）
**P1-5｜[B7] 误格式/类型混淆触发 500 或敏感回显**
- 位置：各端点校验层
- 根因初判：校验缺口
- 建议修复：补齐校验
**P1-6｜[C1] 脱敏字形盲区：['①a emoji 数字 keycap', '①b emoji 内插', '②a 圈号数字', '②b 上标数字', '③a Arabic-Indic', '③b Devanagari', '③c Bengali', '③d 罗马数字+电话语义', '④a 希腊 I/O 混淆', '④b 西里尔混淆'] 成功入库（非 ASCII 数字系统/emoji 字形未覆盖）**

## 4. 关键结论与口径说明

1. **并发 reset-key（A2）**：5 线程并发轮换，最终**无双活可用 key**（仅文件最终 key 可鉴权，线程返回其余 key 全 401）；但 `api_keys` 表 enabled=1 行数达 12（≠1）——表状态与真实鉴权漂移（鉴权以文件为锚，不查表），记 P1（计划字面『enabled>1→P0』供裁量，实际无可用双活）。
2. **并发 publish（C3/D4）**：30 并发发布间歇出现 500（`database is locked`）与 404（`InterfaceError: bad parameter` → 已存在行误报不存在）——连接复用（threading.local 每线程单连接）无隔离所致，记 P1（误 404 比 500 更危险：可致业务误判）。
3. **E3 P0**：`POST /scan/text`（公开端点）body 类型错误时，422 validation_error 消息**回显完整 input（含 admin key）**——公开端点可触发任意 key 形态回显，记 P0。
4. **A4 DNS-rebinding 硬化缺口**：local-login 仅校验 TCP 回环，无 Origin/Sec-Fetch-Site/Host 校验、无 CORS 限制；攻击者域名解析到 127.0.0.1 的恶意页面可同源读取 key 响应（服务仅绑 127.0.0.1 时需本地可达为前提，纵深防御缺口，记 P1）。
5. **脱敏字形盲区（C1/C2/C4）**：变体层覆盖 ASCII 系变体，但 emoji keycap/圈号/上标/Arabic-Indic/天城/孟加拉数字、罗马数字、希腊-西里尔混淆全部放行；身份证 Arabic-Indic 全数字放行；银行卡号（regex 层未列）全部放行——LLM 复核层未配置（降级）无兜底。
6. **B7 int64 溢出 500**：`/traps/99999999999999999999/check-hit` 等超 2^63-1 整数路径/body 参数触发 sqlite3 OverflowError → 500 且回显类名（联动 E3 P2）。
7. **审计链承诺漂移（C6）**：README 宣称 gate_logs『哈希链审计』，实现为单行 `sha256(payload_json)`，无跨行 prev 引用，篡改不可检出。
8. **F 类修复回归全绿（F1–F8）**：第 1 轮全部修复稳定；G1/G2（第1轮遗留 P2）仍未实现，观察保留。
