## 4. 问题清单（逐条：位置/类型/影响/修复建议）

### P1-1 [功能缺陷] scheduler 未 await 异步蜜饵复查

- **位置**：app/services/scheduler.py:138（job_trap_recheck 内 `engine.check_hit(conn, tid, text)`）
- **类型**：async 协程未 await（TrapEngine.check_hit 为 `async def`，trap_engine.py:459）
- **影响**：job_trap_recheck（每 6h）对每条扫描文本调用 check_hit，但**返回协程对象从未执行** → 定时踩饵检测静默失效（不报错、不落地 hit/retired/事件）；Python 会发 `RuntimeWarning: coroutine was never awaited`。API 手动 /traps/{id}/check-hit 正常（api/traps.py:181 有 await）。
- **复现证据**：grep 全库 `.check_hit(` 仅两处调用点；api 侧带 await、scheduler 侧不带。
- **修复建议**：job 内改为事件循环执行——把该段放入 `asyncio.run(_run())`（与同文件 job_scan_dm/job_zhihu_sync 同模式），或 `import asyncio; asyncio.run(engine.check_hit(conn, tid, text))`；并加单测断言 job 执行后 honey_facts.status 变化。
