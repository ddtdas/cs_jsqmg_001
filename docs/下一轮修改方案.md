## 三、新增能力建议（验收暴露的缺口）

1. **se_analysis divergence 深度发散（与 #9 合并实现）**：在确定性规则层之上增加 playbook 推理——按 attack_vector + 命中话术映射「话术套路标签」（中奖/刷单/冒充公检法/杀猪盘/兼职诈骗等）+「建议动作」（不汇款/报警/保留证据/冻结账户），写入 `se_factors.divergence.playbook` 与 `suggested_actions`，前端话术套路列与详情卡受益。当前六键协议稳定，扩展为兼容新增键（`_EMPTY_RESULT` 需同步补默认键）。
2. **HIBP 真实 key 配置**：配置 `AF_HIBP_API_KEY`（环境变量，不入库不进代码），启用在线泄露查询；同时扩充本地 `leak_records` 演示库（按 sha256 哈希存储，保持明文不落库），提升真实 IOC 覆盖面。配置后验证 query 的 HIBP 分支与降级链（429/5xx → 降级不中断）。
3. **拟真发布真实平台对接**：配置任一平台（zhihu cookie / telegram bot token / 微博等 7 平台之一）真实接入 ingest 推送全链（与 #6 合并），让「私信接入」链路从 409 闸控验证升级为真实 webhook 在线实测。
4. **供应链本地 IOC 关联（A队建议采纳）**：`supply-chain/query` 对银行卡号/手机号等非网址 seed 增加本地 IOC 匹配（复用 soc_lib leak_records 哈希匹配），命中则直接出情报节点而非仅 concept_only 提示；未命中保持现有「workflow 全网反查」提示。
5. **chat_import 一键导入落地（若基线确认属验收范围）**：按 `PLAN-聊天记录一键导入.md` 实现，复用现有脱敏强制（assert_clean）+ 降级设计，导入链路纳入 A/B 队复验。
