## 核心速览

- **双形态同一内核（D1）**：WebUI、MCP、curl 都是主控 REST API（`http://127.0.0.1:9200/api/v1`）的客户端。
- **五环功能**：R1 蜜饵诱捕 → R2 话术识别 → R3 账号速查 → R4 五级分级 → R5 证据包 → R6 案例库。
- **反钓鱼伪装（P19）**：多层伪装身份档案 + 假信息主动暴露（HITL）+ 骗子接触登记（脱敏落库 + IOC 掩码 + 同号二次锁定）+ 伪装地图；`/api/v1/cover`（7 paths / 8 ops）与 `/ui/cover` 伪装账号页，详见 `02-API.md` §2.2 与 `反钓鱼伪装验收_队C.md`（全量 479 passed）。
- **合规红线**：非官方工具；只侦查取证不处置执法；处置权归 96110/平台；HITL（永不自动发布）；数据最小化；遵守知乎服务条款与《个保法》。详见 `00-项目概述.md` 与根 `README.md`。
