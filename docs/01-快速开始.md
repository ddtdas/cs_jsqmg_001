# 01 · 快速开始

> 目标：5 分钟内跑起主控并用 WebUI / curl 完成第一次话术检测。
> 项目根（下称 `<ROOT>`）：`C:\Users\Administrator\Desktop\知乎黑客松\金丝雀蜜罐`

## 1. 安装

```bat
cd /d C:\Users\Administrator\Desktop\知乎黑客松\金丝雀蜜罐
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

（可选）构建 WebUI：`webui/dist/` 已包含构建产物，跳过亦可；如需重建：

```bat
cd webui
npm install
npm run build
cd ..
```

## 2. 启动主控

```bat
start.bat
:: 等价于： .venv\Scripts\python.exe -m app.run --host 127.0.0.1 --port 9200
```

> **start.bat 三态**：未运行 → 新窗口启动 + 健康探测 → 自动打开浏览器 `/ui/`；
> 已运行 → 不再重复启动，只多开一个浏览器标签页；探测失败 → 提示查看主控窗口日志。
> 配套：`stop.bat`（停止主控）、`open-console.bat`（项目命令行：cd 项目根 + venv 激活）。

首次启动自动完成：`data/` 目录 → **bootstrap admin key**（`data/bootstrap_admin_key.txt`）→ 幂等建 24 表 → 种子话术词库（≥20 条）。

## 3. 拿到 admin key

**推荐：登录页点"一键登录（本机）"按钮**（WebUI 调用 `POST /api/v1/auth/local-login`，
仅本机回环可调，直接返回 key 完成登录，无需手动读取）。手动获取：

```bat
type data\bootstrap_admin_key.txt
:: 例：af_admin_xxxxxxxx（17 字符）
```

> 也可通过环境变量 `AF_API_KEY` 显式指定 key（优先级高于文件）；
> 本机设置页支持查看当前 key（`GET /api/v1/auth/current-key`）与重置 key
> （`POST /api/v1/auth/reset-key`：confirm=true + reason≥20 字，写 GateLog 审计）。

## 4. 验证（三个入口）

| 入口 | 地址 | 验证什么 |
|---|---|---|
| 健康检查 | http://127.0.0.1:9200/api/v1/system/health | `{ok:true, data:{status:ok, version:1.0.0, db:true, ...}}` |
| WebUI | http://127.0.0.1:9200/ui/ | 登录页 → 一键登录（本机）或粘贴 key → 仪表盘 |
| Swagger | http://127.0.0.1:9200/docs | 交互式调试全部端点 |

```bash
# 第一条话术检测（无需 key）
curl -X POST http://127.0.0.1:9200/api/v1/scan/text \
  -H "Content-Type: application/json" \
  -d '{"text":"杀猪盘带你投资稳赚不赔，加老师微信"}'
# -> {ok:true, data:{detection_id, grade, grade_reason, hits, ...}}

# 受保护端点示例（需 key）
curl http://127.0.0.1:9200/api/v1/system/stats -H "X-API-Key: af_admin_xxxxxxxx"
```

## 6. 常见问题

| 症状 | 处理 |
|---|---|
| 端口被占用 | 改端口：`start.bat` 的 `set PORT=` 或 `.env` 的 `AF_PORT=` |
| WebUI /ui/ 404 | 未构建前端：先 `cd webui && npm install && npm run build`（或确认 `webui/dist/` 存在） |
| 401 unauthorized | key 错误/未带；用 `data/bootstrap_admin_key.txt` 内容，走 `X-API-Key` 或 `Authorization: Bearer` |
| LLM 未生效 | `.env` 配置 `AF_LLM_BASE_URL/AF_LLM_API_KEY/AF_LLM_MODEL` 三者齐备；未配置则 D5 降级纯规则，功能不瘫 |
